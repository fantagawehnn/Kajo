# KAJO Recorder – Minimaler Garmin-Prototyp

Ziel dieses Prototyps ist ausschließlich:
1. Auf der Venu 3S eine Aktivität über Garmin `ActivityRecording` starten.
2. Nach erfolgreichem Start einen sichtbaren Sekunden-Timer anzeigen.

Die Aufzeichnung wird als Garmin-Aktivität mit der Sportart `Kayaking` angelegt. Es gibt bewusst noch keine Pause-, Stopp-, Speichern-, Runden-, GPS-, Puls-, Trainingsplan-, Synchronisations- oder Einstellungsfunktionen.

## Build

Das Projekt ist ein eigenständiges Connect IQ Monkey C-Projekt. In Garmin Connect IQ / VS Code den Ordner `KajoRecorder` als Projekt öffnen und für `venu3s` bauen.
